- **Setup Engine (M1)**: Saya menambahkan file `.env` di _root_ sebagai templat _environment variables_ Turso.

- **Swiper.js (M2)**: `ProjectSlider.tsx` kini memanfaatkan pustaka standar industri `swiper/react` untuk navigasi _carousel_ yang lebih dinamis.
