# 🧠 Selamat Datang di Antigravity Brain (Second Brain)

Folder ini adalah pusat otak konfigurasi (*Configuration Brain*) dari proyek ini, yang dirancang khusus untuk memandu agen AI seperti Antigravity. Jika kamu adalah agen AI yang baru saja masuk ke proyek ini, ikuti langkah orientasi ini secara ketat:

1. **Baca Konteks Proyek**: Baca `docs/milestones/00-ROADMAP.md` dan `MEMORY.md` (di root proyek) untuk melihat status pengembangan terakhir dan target besar.
2. **Pahami Istilah & Arsitektur**: Baca `docs/GLOSSARY.md` untuk kamus proyek, dan `docs/adr/` untuk mengetahui keputusan-keputusan teknis (Architecture Decision Records) masa lalu.
3. **Patuhi Aturan (Rules)**: Kamu **WAJIB** mematuhi semua aturan yang terdapat di dalam folder `.agents/rules/` (Core Behavior, Frontend, Backend). Aturan ini otomatis dimuat ke dalam memori.
4. **Gunakan Keahlian (Skills)**: Folder `.agents/skills/` berisi puluhan kemampuan prosedural, *tools*, dan otomatisasi alur kerja (*workflows*). Periksa dan gunakan *skill* yang sesuai (seperti `test-driven-dev`, `project-workflows`, `grill-me`, dll) saat kamu menemui jalan buntu atau membutuhkan panduan prosedural standar.

*Semua catatan kerja lama (history), milestones, dan keputusan (decisions) disimpan dengan rapi di dalam folder `docs/` pada root proyek.*
