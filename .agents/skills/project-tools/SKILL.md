# Project Tools

This skill contains utility scripts for database seeding, component creation, and project initialization.
You can run these scripts from `.agents/skills/project-tools/scripts/` using `bun run`.

Available scripts:
- `setup-husky.ts`
- `check-env.ts`
- `init-project.sh`
- `create-component.ts`
- `seed-database.ts`
