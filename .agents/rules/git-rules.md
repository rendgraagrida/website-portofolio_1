ATURAN GIT & COMMITS: 
Wajib patuhi standar "Conventional Commits". Setiap pesan commit harus mengikuti format berikut:
- `feat: [Deskripsi]` untuk penambahan fitur baru.
- `fix: [Deskripsi]` untuk perbaikan bug.
- `docs: [Deskripsi]` untuk pembaruan dokumentasi (termasuk folder `.agents`).
- `chore: [Deskripsi]` untuk pemeliharaan rutin, update dependensi, atau *formatting*.
- `refactor: [Deskripsi]` untuk restrukturisasi kode tanpa mengubah fungsionalitas.

Hal ini mempermudah pelacakan sejarah perubahan (*changelog*) secara otomatis.
